# Udemy LangGraph Course

This project is a study of the Udemy LangGraph course.

## Setup

This project uses `uv` as a package manager. To set up the project, please follow these steps:

1.  Install `uv`:
    ```bash
    pip install uv
    ```
2.  Create a virtual environment:
    ```bash
    uv venv
    ```
3.  Activate the virtual environment:
    ```bash
    source .venv/bin/activate
    ```
4.  Sync the dependencies:
    ```bash
    uv sync
    ```

## Running the project

To run the project, please execute the following command:
```bash
python main.py
```
